什麼是 N+Claw Pro

從 macOS 桌面啟動，在瀏覽器裡開始對話。不必先學指令，把工程問題交給熟悉領域的工作助手。v0.20 起內建七位工程助手，從估價、法規到工地日報都能直接開始。

02

工程的答案，
有脈絡可循。

工程知識庫 · 規劃中

規範條文、廠商行情與工法步驟，是工程判斷的基礎。知識庫將把相關內容帶入對話，讓引用可追溯；目前版本可匯入自己的資料建立知識庫，完整工程知識庫檢索持續擴充中。

03

熟悉的工序，
成為順手技能。

技能與工作流

消防灑水管徑、CAD／DWG 讀取、估算報價、規範查詢、PDF 圖說解析、廠商比價、工法 SOP 與設計審查，是完整八項技能的方向。目前提供一項示範技能，其餘留待 v1。多模型統一入口與任務路由亦屬產品規劃。

04

離開桌面，
工作不必斷線。

從手機接著做 · 規劃中

讓現場與辦公室之間的工作能接續，是下一步的方向。現階段僅提供 macOS 桌面版；手機遠端存取、同步及續作尚未列為已交付功能。

05

資料留在哪，
先說清楚。

安全與資料邊界

桌面啟動不等於所有資料都不出門。首次安裝需要連網；若使用雲端模型，送出的內容仍會由對應服務處理。請勿在早期版本輸入客戶機密；離線推論與資料完全不外傳，並非目前版本的保證。

系統需求

  • macOS 11 以上，Apple Silicon（M1 以後）
  • 下載約 212 MB，安裝後約 600 MB 硬碟空間
  • 需連網使用雲端模型

試用前，請先了解

  • 七位工程助手皆為早期版本，工程判斷須由專業人員核對
  • 知識庫可匯入自己的 Markdown 資料夾（如 Obsidian）
  • 未提供儲值、計量與推薦碼
  • 已通過 Apple 公證，雙擊即可開啟
安裝與首次啟動
  1. 下載 DMG，雙擊掛載。
  2. 將 N+Claw Pro 拖到 Applications 資料夾。
  3. 雙擊 Applications 裡的 N+Claw Pro 開啟（已通過 Apple 公證）。
  4. 登入或輸入 N+Claw 連線金鑰後，從左側選一位工程助手開始對話。
